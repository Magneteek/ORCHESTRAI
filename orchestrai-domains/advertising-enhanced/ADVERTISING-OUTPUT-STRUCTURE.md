## File Naming Conventions

### Standard Format
- **Date Format**: YYYY-MM-DD
- **Client Names**: lowercase-with-hyphens
- **Campaign Names**: descriptive-lowercase-with-hyphens
- **Version Control**: v1, v2, v3 for iterations

### Example File Names
```
grand-slam-offer-acme-corp-2024-01-15-v2.md
meta-hooks-collection-fitness-brand-2024-01-15.md
linkedin-b2b-headlines-saas-client-2024-01-15.md
godfather-offer-components-ecommerce-2024-01-15.json
```

## Output Specifications for Each Agent

### Offer Creation Specialist
- **Primary Path**: `/Copy/Offers/`
- **Formats**: Markdown files with JSON data files for structured elements
- **Required Files**: Analysis, components, testing framework

### Meta Ads Specialist  
- **Primary Path**: `/Copy/Platform-Copy/Meta-Ads/`
- **Focus**: Creative copy, hooks, scripts
- **Mobile Optimization**: All copy optimized for mobile viewing

### LinkedIn Ads Specialist
- **Primary Path**: `/Copy/Platform-Copy/LinkedIn-Ads/`
- **Focus**: Professional B2B copy, thought leadership
- **Character Limits**: Adherence to LinkedIn specifications

### Google Ads Specialist
- **Primary Path**: `/Copy/Platform-Copy/Google-Ads/`
- **Focus**: Search intent alignment, Quality Score optimization
- **Extensions**: Complete ad extension copy

### Reddit Ads Specialist
- **Primary Path**: `/Copy/Platform-Copy/Reddit-Ads/`
- **Focus**: Community-appropriate, authentic messaging
- **Transparency**: Clear promotional disclosure

### Copy Variation Generator
- **Primary Path**: `/Copy/Copy-Variations/`
- **Focus**: Systematic A/B testing, psychological triggers
- **Testing Framework**: Statistical significance requirements

## Integration Benefits

1. **Clean Organization**: Easy to find and reference all generated content
2. **Version Control**: Clear tracking of iterations and improvements
3. **Performance Analysis**: Organized structure for analyzing what works
4. **Template Building**: Successful copy becomes templates for future use
5. **Client Presentations**: Professional organization for client deliverables
6. **Cross-Agent Learning**: Shared insights and successful patterns

This structure ensures all advertising agents have a clear, organized place to output their work while maintaining the high standards and systematic approach that ORCHESTRAI represents.
