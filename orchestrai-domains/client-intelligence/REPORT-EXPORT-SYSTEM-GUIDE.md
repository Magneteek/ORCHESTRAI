## 🎨 Features in Detail

### 1. PDF Export

**What it does**: Generates a high-quality PDF file and downloads it immediately

**How to use**:
1. Click the **PDF** button in export toolbar
2. OR press **Ctrl/Cmd + E**
3. PDF downloads automatically

**Technical Details**:
- Uses html2pdf.js library
- High-quality (scale: 2, DPI: 192)
- Optimized page breaks
- Preserves all styling and charts
- File naming: `report-name-timestamp.pdf`

**Best for**:
- Client presentations
- Printing
- Email attachments
- Archiving

---

### 2. Plain Text Copy

**What it does**: Copies the entire report as clean, formatted plain text

**How to use**:
1. Click the **Text** button
2. OR press **Ctrl/Cmd + Shift + C**
3. Status message confirms copy
4. Paste anywhere (Cmd/Ctrl + V)

**Output Format**:
```
Intelligence Report Title
==========================

Section Heading
---------------

Paragraph content with line breaks preserved.

- List items
- Preserved
- With bullets

Table data in plain text format
```

**Best for**:
- Email bodies
- Plain text editors
- Quick notes
- Text-only platforms

---

### 3. Markdown Copy (Notion-Compatible)

### 6. Google Sheets Format

**What it does**: Copies data as tab-separated values (TSV) ready for Sheets

**How to use**:
1. Click the **Sheets** button
2. Status: "✅ Copied! Paste directly into Google Sheets"
3. Open Google Sheets
4. Click any cell
5. Paste (Cmd/Ctrl + V)
6. Perfect formatting!

**Why TSV (not CSV)**:
- Google Sheets automatically formats TSV perfectly
- Preserves table structure
- No quote escaping issues
- Headers formatted correctly

**Best for**:
- Quick data transfer to Sheets
- Collaborative analysis
- Creating dashboards
- Sharing with teams

## 🔧 Technical Architecture

### Module Structure

```javascript
class ReportExportManager {
  constructor()                // Initialize export manager
  init()                      // Setup toolbar and listeners

  // Export Methods
  exportToPDF()               // PDF download
  copyAsPlainText()           // Plain text clipboard
  copyAsMarkdown()            // Markdown clipboard
  exportAsCSV()               // CSV file download
  exportAsJSON()              // JSON file download
  copyForGoogleSheets()       // TSV clipboard

  // Helper Methods
  extractPlainText()          // Parse HTML to text
  convertToMarkdown()         // Parse HTML to MD
  convertToCSV()              // Extract tables to CSV
  convertToTSV()              // Extract tables to TSV
  extractStructuredData()     // Parse HTML to JSON
  downloadFile()              // Browser download helper
  loadScript()                // Dynamic script loader
}
```

## 🐛 Troubleshooting

### Issue: PDF Export Button Does Nothing

**Cause**: html2pdf.js not loaded

**Solution**:
1. Check internet connection
2. Module auto-loads library
3. Wait 2-3 seconds after page load
4. Try again

**Fallback**: Use browser print (Cmd/Ctrl + P)

---

### Issue: Copy to Clipboard Fails

**Cause**: Browser permissions or HTTPS required

**Solution**:
1. Ensure using HTTPS or localhost
2. Grant clipboard permissions when prompted
3. Try keyboard shortcut instead of button
4. Check browser console for errors

**Fallback**: Select text manually and copy

---

### Issue: Export Toolbar Not Appearing

**Cause**: JavaScript not loaded or errors

**Solution**:
1. Check browser console for errors
2. Verify report-export-module.js is loaded
3. Refresh page (Cmd/Ctrl + R)
4. Clear browser cache

**Manual Fix**:
```javascript
// In browser console
reportExport.injectExportToolbar();
```

---

### Issue: Markdown Formatting Wrong in Notion

**Cause**: Direct paste may not work

**Solution**:
1. In Notion, type `/code`
2. Create code block
3. Paste markdown
4. Click "..." menu
5. Select "Turn into page"

---

### Issue: Google Sheets Import Messy

**Cause**: Using CSV instead of Sheets format

**Solution**:
- Use the **Sheets** button (not CSV)
- Sheets button copies TSV format
- TSV auto-formats perfectly in Sheets
