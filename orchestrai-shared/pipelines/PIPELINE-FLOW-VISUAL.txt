================================================================================
  KEY CHARACTERISTICS
================================================================================

GATE 0 (Outline Approval):
  ⭐ MANDATORY BLOCKING GATE
  ⭐ Runs ONCE per article (not in revision loops)
  ⭐ Cannot be skipped or bypassed
  ⭐ Requires explicit user confirmation
  ⭐ Enforces CLAUDE.md mandatory workflow

GATES 1-4 (Creation & Validation):
  • Run in sequence for each cycle
  • Can repeat up to 2 times in revision loop
  • Must ALL pass for completion

GATE 5 (Revision Loop):
  • Triggered when Gate 3 or 4 fails
  • Compiles targeted fix instructions
  • Maximum 2 cycles before escalation

GATE 6 (Completion):
  • Only reached after passing ALL gates
  • No false "complete" without validation
  • Production-ready guarantee

================================================================================
  QUALITY THRESHOLDS
================================================================================

AI Detection:        <25% (ideal: 15-25%)
Paragraph Dist:      40% short, 40% medium, 20% long (±5% tolerance)
Bullet Lists:        Maximum 20 per article
Bold Text:           Maximum 15 instances (emphasis only)
Tables:              Maximum 6 per article
Word Count:          Target ±10%

================================================================================
  FAIL-FAST PRINCIPLE
================================================================================

If ANY gate fails, pipeline stops immediately:
  • Outline missing (Gate 0)     → STOP, create outline first
  • Outline not approved (Gate 0) → PAUSE, revise and restart
  • File missing (Gate 2)         → STOP, investigate silent failure
  • AI detection high (Gate 3)    → Compile fixes, trigger revision
  • Quality metrics off (Gate 4)  → Compile fixes, trigger revision
  • Max revisions (Gate 5)        → STOP, escalate to human
