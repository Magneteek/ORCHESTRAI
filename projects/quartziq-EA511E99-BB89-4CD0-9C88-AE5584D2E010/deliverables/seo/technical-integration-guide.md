## Performance SEO Factors

### Core Web Vitals Optimization
**Largest Contentful Paint (LCP)**: Target <2.5 seconds
- **Hero image optimization**: WebP format, appropriate sizing
- **Critical CSS**: Inline above-the-fold styling
- **Font preloading**: Custom fonts loaded immediately

**First Input Delay (FID)**: Target <100ms  
- **JavaScript optimization**: Async/defer non-critical scripts
- **Third-party scripts**: Minimize impact of tracking codes
- **Event handlers**: Efficient click and form interactions

**Cumulative Layout Shift (CLS)**: Target <0.1
- **Image dimensions**: Explicit width/height attributes
- **Font loading**: Prevent text shifting during font load
- **Ad spaces**: Reserved space for dynamic content

### Mobile Performance
- **Mobile-first indexing**: Optimized mobile experience
- **Touch targets**: 44px minimum size
- **Viewport configuration**: Proper mobile viewport settings
- **AMP consideration**: For blog content and resources
