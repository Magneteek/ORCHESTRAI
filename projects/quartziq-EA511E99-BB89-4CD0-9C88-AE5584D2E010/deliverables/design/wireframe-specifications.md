# QuartzIQ Homepage - Wireframe Design Specifications

## Page Layout Architecture

### Header Section (Sticky Navigation)
**Height**: 70px desktop, 60px mobile
**Elements**:
- Logo (left-aligned): QuartzIQ brand mark
- Navigation menu (center): Services, About, Resources, Contact
- CTA button (right-aligned): "Free Growth Audit"

**Mobile Considerations**:
- Hamburger menu for navigation
- Logo centered, menu icon right-aligned
- CTA button accessible in mobile menu

---

## Hero Section Layout

### Desktop Layout (1200px+ screens)
**Section Height**: 600px minimum, up to 80vh
**Grid Structure**: 12-column responsive grid

#### Content Area (Columns 1-7)
- **Headline (H1)**: 48px font size, bold weight
  - Position: Top-left alignment
  - Line height: 1.2
  - Max width: 500px
  
- **Subheadline (H2)**: 24px font size, medium weight  
  - Position: Below headline, 20px margin
  - Line height: 1.4
  - Max width: 550px
  
- **Supporting Text**: 18px font size, regular weight
  - Position: Below subheadline, 24px margin
  - Line height: 1.5
  - Max width: 500px

- **Primary CTA Button**: 
  - Position: Below text, 32px margin
  - Size: 180px width × 50px height
  - Font: 16px, semibold
  - Color: Primary brand color with white text
  
- **Secondary CTA Link**:
  - Position: Below button, 16px margin  
  - Font: 16px, underlined
  - Color: Secondary brand color

#### Visual Area (Columns 8-12)
- **Hero Image/Graphic**: Dashboard mockup or automation visualization
- **Trust Indicators**: Small client logos or certification badges
- **Position**: Right-aligned, full column width

### Mobile Layout (320px-768px screens)
**Section Height**: 500px minimum
**Structure**: Single column, centered content

- **Content Order**: Logo, headline, subheadline, text, CTA, visual
- **Headline**: 36px font size, centered
- **CTA Button**: Full-width or 280px centered
- **Visual**: Reduced size, centered below content

# Responsive Design Specifications

## Breakpoint Strategy
- **Mobile**: 320px - 767px
- **Tablet**: 768px - 1023px  
- **Desktop**: 1024px - 1439px
- **Large Desktop**: 1440px+

## Mobile-First Considerations

### Typography Scale
- **Mobile headlines**: 28px - 36px
- **Mobile body**: 16px - 18px
- **Mobile buttons**: 44px minimum height
- **Line spacing**: 1.4 - 1.6 for readability

### Touch Targets
- **Minimum size**: 44px × 44px
- **Spacing**: 8px minimum between targets
- **Button padding**: 12px vertical, 24px horizontal

### Content Prioritization
1. **Hero message**: Primary value proposition
2. **Primary CTA**: Most important action
3. **Key benefits**: Top 3 benefits only
4. **Trust indicators**: Essential social proof
5. **Secondary elements**: Collapsible or hidden

# Conversion Optimization Framework

## Heat Mapping Strategy
- **Primary focus areas**: Hero CTA, benefit headlines, guarantee section
- **Click tracking**: All CTA buttons, navigation links, secondary offers
- **Scroll depth**: Content engagement measurement
- **Mobile behavior**: Touch patterns and swipe interactions

## A/B Testing Elements

### Hero Section Tests
- **Headline variations**: Fear-based vs. benefit-focused
- **CTA button colors**: Brand color vs. contrasting colors
- **Hero image**: Product shots vs. abstract graphics
- **CTA text**: "Free Audit" vs. "Get Started" vs. "Schedule Call"

### Layout Tests
- **Problem section**: Grid vs. list layout
- **Solution section**: Timeline vs. cards vs. accordion
- **Trust elements**: Top of page vs. bottom placement
- **Form length**: Minimal vs. detailed lead capture

## Psychological Trigger Implementation

### Scarcity Elements
- **Limited spots**: "Only 5 spots available for Q1 2025"
- **Countdown timers**: For special offers or consultations
- **Waitlist options**: When capacity is reached

### Social Proof Integration
- **Live notifications**: "John from Miami Dental just scheduled..."
- **Recent activity**: "15 dental suppliers joined this week"
- **Client count**: "Trusted by 200+ dental equipment suppliers"

### Authority Indicators  
- **Team credentials**: Industry experience highlights
- **Certifications**: Marketing automation and dental industry credentials
- **Media mentions**: Press coverage or industry recognition
- **Speaking engagements**: Conference presentations or webinars

# Technical Implementation Notes

## Performance Optimization
- **Image optimization**: WebP format, lazy loading, responsive images
- **Critical CSS**: Above-the-fold styling prioritized
- **JavaScript**: Async loading for non-critical elements
- **Font loading**: Preload custom fonts, fallback system fonts

## Analytics Integration
- **Goal tracking**: CTA clicks, form submissions, phone calls
- **Event tracking**: Scroll depth, time on section, video plays
- **Conversion funnel**: Multi-step process tracking
- **Attribution**: UTM parameters for traffic source analysis

## Accessibility Requirements
- **WCAG 2.1 AA**: Minimum compliance standard
- **Color contrast**: 4.5:1 ratio for normal text, 3:1 for large text
- **Keyboard navigation**: Tab order optimization
- **Screen readers**: Alt text, ARIA labels, semantic HTML
- **Focus indicators**: Clear visual focus states

## SEO Technical Elements
- **Structured data**: Organization, service, review schemas
- **Meta tags**: Title, description, Open Graph, Twitter Cards
- **Internal linking**: Contextual links to service pages
- **Image SEO**: Descriptive filenames, alt text, captions

This wireframe specification provides detailed guidance for creating a conversion-optimized homepage that addresses QuartzIQ's unique positioning in the dental equipment supplier market while maintaining professional credibility and user experience best practices.
