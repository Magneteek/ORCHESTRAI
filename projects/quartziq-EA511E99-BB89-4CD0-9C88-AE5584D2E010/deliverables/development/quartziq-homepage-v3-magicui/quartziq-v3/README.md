# QuartzIQ Homepage V3 - MagicUI Enhanced

## Overview

This is the third iteration of the QuartzIQ homepage, featuring enhanced interactivity and visual appeal through the integration of MagicUI components. Built with Next.js 15, TypeScript, Tailwind CSS v4, and ShadCN UI.

## Key Features

### 🎨 **MagicUI Components**
- **Orbiting Circles**: Dynamic animated circles representing different aspects of dental automation (trust, leads, analytics, communication)
- **Particles**: Subtle background particle effects using QuartzIQ brand colors
- **Ripple Effects**: Interactive button animations for enhanced user engagement
- **Animated Beams**: Visual connection elements between components

### 🎯 **QuartzIQ Brand Integration**
- **Brand Colors**: Full integration of QuartzIQ's color palette (#1A2944, #3F86A4, #357494)
- **Content Strategy**: Conversion-optimized copy targeting the 79% lead conversion failure pain point
- **Trust Elements**: Trust-to-Lead Guarantee prominently featured
- **Visual Hierarchy**: Clean, professional layout matching dental industry standards

### 📱 **Technical Implementation**
- **Next.js 15** with App Router and TypeScript
- **Tailwind CSS v4** with inline theme configuration
- **ShadCN UI** components for consistency
- **Responsive Design** optimized for all device types
- **Performance Optimized** with Core Web Vitals compliance
