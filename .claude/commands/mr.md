# Mini Report (Short Alias)

**Alias for**: `/mini-report`

Generate condensed single-page intelligence dashboard.

**Usage**:
```
/mr [client-name or project-uuid]
```

**Output**: Single-page executive dashboard (3-4 printed pages, <50KB)

**This command executes**: `/mini-report` with all requirements.

See `/mini-report` for complete documentation.
