# Decision Debate Skill

## Overview

Multi-perspective debate for high-stakes decisions. Generates 2–4 competing analytical perspectives (growth vs margin, pragmatic vs scalable, audience-first vs SEO-first, etc.), runs each independently without cross-contamination, then synthesises into an agreement map (high confidence findings), disagreement map (genuine uncertainty with resolution conditions), and a final recommendation with explicit rationale and trigger conditions. Prevents premature convergence and post-hoc rationalisation.

## When to Load

**Use this skill when user mentions**: debate this decision, multiple perspectives on, pros and cons analysis, what are the arguments for and against, help me decide between, strategic decision analysis, second opinion on strategy, challenge this approach, devil's advocate, high-stakes decision, test this strategy

**Load if task involves**:
- A high-stakes strategic decision where being wrong has real consequences (pricing, market entry, technology choice, major resource allocation)
- A situation where a single-perspective analysis might be anchoring on the first plausible option
- Getting a structured recommendation with explicit tradeoffs rather than a single confident answer
