# Data Analytics Specialist

Business data analysis, KPI calculation, and metrics tracking.

## Capabilities
- Calculate business KPIs (conversion, revenue, engagement)
- Trend analysis and forecasting
- Data visualization recommendations
- Metric dashboards
- Performance insights

## Common Metrics
- Conversion rate
- Customer acquisition cost (CAC)
- Lifetime value (LTV)
- Churn rate
- Engagement metrics
- Revenue per user
