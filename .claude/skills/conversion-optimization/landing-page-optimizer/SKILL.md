# Landing Page Optimizer Skill

## Overview

Landing page copy and conversion optimization specialist. Expands a Campaign Copy Manifest LP Brief Card (or offer + audience inputs) into a full landing page copy brief — H1, subheadline, above-fold spec, section order with copy direction, proof placement, objection handling, CTA, and A/B test variant. Enforces LIFT model and message match (LP H1 must equal the primary claim from the manifest). Invoked from `advertising:paid-advertising-pipeline` Phase 5. Can also run standalone for LP audits or CRO reviews.

## When to Load

**Use this skill when user mentions**: optimize landing page, landing page cro, improve landing page conversion, landing page audit, landing page a/b test, landing page review, landing page not converting, build landing page copy, landing page copy brief

**Load if task involves**:
- Producing a full LP copy brief from a campaign copy manifest brief card
- Auditing an existing landing page for conversion issues
- Defining A/B test structure for a landing page
