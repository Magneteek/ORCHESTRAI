# Multilanguage Content Pipeline Skill

## Overview

Orchestrates end-to-end multilanguage content production. Takes source content (or creates it) and produces validated, culturally-adapted versions in N target languages in parallel. Each language version gets its own SERP research, cultural adaptation, AI phrase detection, and language purity validation before delivery. Outputs all versions together with hreflang map and CMS implementation instructions.

## When to Load

**Use this skill when user mentions**: multilanguage content, content in multiple languages, translate and adapt content, produce content in slovenian and german, localize content for multiple markets, international content production, content for EU markets, multilingual content pipeline, produce SL DE NL content

**Load if task involves**:
- Producing content in more than one language
- Adapting existing content for multiple market variants
- Running a full multilanguage content production workflow with quality gates
