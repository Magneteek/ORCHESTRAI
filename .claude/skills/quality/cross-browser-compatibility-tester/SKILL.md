# Cross-Browser Compatibility Tester

## Overview

Audits HTML/CSS/JS code for cross-browser compatibility issues across Chrome, Firefox, Safari, and Edge. Identifies CSS properties, JavaScript APIs, and layout patterns that behave differently across browsers and provides specific fixes.

## When to Load

**Use this skill when user mentions**: cross browser testing, browser compatibility, safari rendering issue, firefox css bug, edge compatibility, browser support audit, works in chrome but not safari, css cross browser, browser compatibility check, multi browser test

**Load if task involves**:
- Auditing a website or web component for cross-browser rendering differences
- Identifying CSS/JS features with limited browser support
- Producing a browser compatibility fix list before deployment
