# SEO URL Extract Skill

## Overview

Single-URL on-page extractor — zero API cost. Paste any URL and get back: title, all meta tags, full heading outline (H1–H6 in document order), and every JSON-LD schema block parsed as structured JSON. Equivalent to Thorbit Crawl's "URL Extract" endpoint.

## When to Load

**Use this skill when user mentions**: extract page, URL extract, schema check, schema analysis, structured data, competitor page audit, heading structure, meta tags, JSON-LD, what schema does this page use, check meta description, page structure, single page SEO check

**Load if task involves**:
- Auditing a competitor's on-page SEO without a full crawl
- Checking what schema types a top-ranking page uses
- Verifying a client page has correct meta tags / canonical
- Extracting heading structure for content brief research
- Confirming JSON-LD is correctly implemented
