# Page Performance Analyzer

## Overview

Analyses SEO performance at the page level for a domain: which pages drive traffic, which underperform for their target keyword, which have technical issues suppressing rankings, and which pages are cannibalising each other.

## When to Load

**Use this skill when user mentions**: page performance, which pages are ranking, page level analysis, best performing pages, worst performing pages, page seo audit, page traffic analysis, url performance, page rankings breakdown, content performance analysis

**Load if task involves**:
- Determining which pages drive the most organic traffic and which underperform
- Identifying pages with technical SEO issues (slow, thin content, duplicate tags)
- Spotting keyword cannibalisation between pages
