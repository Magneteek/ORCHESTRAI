# Keyword Opportunity Finder

## Overview

Identifies quick-win keyword opportunities for a domain: keywords ranking in positions 4–20 with high click potential, keywords with CTR below position average, and gap keywords competitors rank for but the domain doesn't.

## When to Load

**Use this skill when user mentions**: keyword opportunities, quick win keywords, ranking gaps, keywords to improve, underperforming keywords, keywords close to page one, position 4 to 20 keywords, keyword improvement opportunities, where can we gain rankings

**Load if task involves**:
- Finding keywords where a small ranking improvement yields significant traffic gains
- Identifying underperforming keywords where the page could be optimised
- Finding competitor keyword gaps to target with new content
