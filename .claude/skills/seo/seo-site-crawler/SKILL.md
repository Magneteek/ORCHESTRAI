# SEO Site Crawler Skill

## Overview

Full website crawler using Firecrawl — maps all URLs on a domain and extracts every page as clean markdown. Use for competitor content audits, content gap analysis, site migration, and bulk content extraction. Fills the Site Mapper + Site Extractor gap from Thorbit Crawl.

## When to Load

**Use this skill when user mentions**: crawl website, site crawler, crawl competitor, extract all pages, site map, content audit, site migration, bulk scrape, all pages from site, website content extraction

**Load if task involves**:
- Mapping all pages on a competitor's site
- Content gap analysis requiring actual page content
- Pre-migration content inventory
- Extracting all blog posts or service pages from a domain
