# Sentiment Analysis Specialist

Multi-language sentiment analysis with emotion detection.

## Capabilities
- Sentiment polarity (positive/negative/neutral)
- Emotion detection (joy, sadness, anger, fear)
- Aspect-based sentiment
- Multi-language support (EN, ES, NL, DE, SL)
- Confidence scoring

## Output
```
Sentiment: Positive (87% confidence)
Dominant Emotion: Joy
Score: +0.73 (range: -1 to +1)
```
