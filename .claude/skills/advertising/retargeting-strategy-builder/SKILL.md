# Retargeting Strategy Builder

## Overview

Builds a multi-stage retargeting audience strategy and campaign structure for Google and Meta. Maps audience segments by funnel stage (awareness → consideration → conversion → retention), defines audience definitions per platform, and produces a ready-to-implement campaign spec.

## When to Load

**Use this skill when user mentions**: retargeting strategy, remarketing campaigns, retargeting audiences, website visitor retargeting, cart abandonment retargeting, facebook retargeting, google remarketing, build retargeting funnel, warm audience strategy, lost lead retargeting

**Load if task involves**:
- Building a retargeting campaign strategy from scratch
- Creating audience segments based on site behaviour or CRM data
- Designing a post-conversion retention campaign sequence
