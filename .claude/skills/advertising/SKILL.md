# Advertising Domain

## Overview

Specialized agents for advertising tasks.

Keywords: advertising, direct response, copywriting, sales copy, VSL, offer creation, Hormozi, Suby, conversion copy

## Available Skills

### Pipelines (start here for full campaign work)
- **paid-advertising-pipeline** — End-to-end paid campaign: intelligence → strategy → offer → manifest → copy (all channels) → compliance gate → LP copy brief → campaign structure → launch package
- **campaign-copy-manifest** — Shared research brief driving both ad copy and LP copy from one source: competitor creative research + audience language mining + message architecture + per-asset brief cards (LP/Google/Meta/LinkedIn/Reddit). Enforces message match (ad headline ≡ LP H1). Run between offer architecture and copy production.

### Platform specialists (invoked by pipeline)
- **google-ads-specialist** — Search intent matching, RSA copy, Quality Score, keyword strategy
- **meta-ads-specialist** — Facebook/Instagram campaigns, creative strategy, cold + retargeting
- **linkedin-ads-specialist** — B2B advertising, professional audience targeting, lead gen forms
- **reddit-ads-specialist** — Community-native advertising, authentic voice, subreddit targeting
- **ad-copy-variation-generator** — A/B copy variations, psychological triggers, testing matrix

### Copy & offer (standalone or pipeline)
- **direct-response-copywriter** — VSLs, long-form sales letters, email sequences (Hormozi + Suby frameworks)
- **offer-creation-specialist** — Grand Slam Offers, Godfather Offer, value stacks, value ladders
