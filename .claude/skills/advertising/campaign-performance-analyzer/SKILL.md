# Campaign Performance Analyzer

## Overview

Analyses paid ad campaign results against the original brief targets from campaign-copy-manifest. Identifies winning and losing ad sets, calculates ROAS/CPA vs. targets, and produces a prioritised budget reallocation recommendation.

## When to Load

**Use this skill when user mentions**: campaign performance, ad results, google ads performance, meta ads results, roas analysis, cpa analysis, which ads are working, budget reallocation, pause underperforming ads, ad set analysis, campaign review, advertising performance report

**Load if task involves**:
- Comparing campaign results against targets set in the campaign brief
- Determining which ad sets/creatives to scale and which to pause
- Producing a budget reallocation recommendation based on performance data
