## Visual Design Rules (REQUIRED — applies to all webdev skills)

These are hard rules for all UI/frontend output. Never violate them.

### Forbidden Patterns
1. **No single-sided borders** — `border-left`, `border-right`, `border-top`, `border-bottom` as standalone decorative elements are forbidden. Use full borders, outlines, or background shapes instead.
2. **No gradients** — `background: linear-gradient(...)`, `background: radial-gradient(...)`, `gradient-to-*` Tailwind classes are forbidden. Use flat solid colours only.

### Why
Single-sided borders read as unfinished UI and create visual noise without structure. Gradients age quickly, look generic, and fight clean typography. Flat + solid = timeless.
