## State Transitions

```
┌────────────────────────────────────────────────────────┐
│                    State Management                     │
└────────────────────────────────────────────────────────┘

Step 1: Template Selection
─────────────────────────────
State:
  - selectedTemplate: null
  - fieldValues: {}
  - targeting: default
  - budget: default

Action: User clicks "Use Template"
Result:
  - selectedTemplate: selected
  - advance to Step 2

Step 2: Dynamic Fields
──────────────────────
State:
  - selectedTemplate: set
  - fieldValues: populating
  - fieldValuesValid: false → true

Action: User fills all required fields
Result:
  - fieldValues: complete
  - fieldValuesValid: true
  - "Next" button enabled

Step 3: Configuration
─────────────────────
State:
  - campaignName: empty → filled
  - targeting: default → configured
  - budget: default → configured
  - targetingBudgetValid: false → true

Action: User completes all configuration
Result:
  - All values set
  - targetingBudgetValid: true
  - advance to Step 4

Step 4: Preview
───────────────
State:
  - All previous states preserved
  - Preview generated from values

Action: User clicks "Launch Campaign"
Result:
  - API call initiated
  - Loading state shown
  - On success: redirect
  - On error: show error message
```

## Validation Flow

```
┌────────────────────────────────────────────────────────┐
│                  Validation Pipeline                    │
└────────────────────────────────────────────────────────┘

Client-Side Validation
──────────────────────
1. Form Level (React Hook Form)
   ├─ Field-level validation (onChange)
   ├─ Schema validation (Zod)
   └─ Form-level validation (onSubmit)

2. Component Level
   ├─ DynamicFieldsForm validates field values
   ├─ TargetingBudgetForm validates config
   └─ Parent validates step completeness

3. Navigation Control
   ├─ Disable "Next" if current step invalid
   ├─ Disable "Launch" if any validation fails
   └─ Allow "Back" anytime (no validation)

Server-Side Validation
──────────────────────
1. Authentication Check
   └─ Verify user session

2. Request Schema Validation
   └─ Validate with Zod schema

3. Database Validation
   ├─ Template exists
   ├─ User has ad account access
   └─ Field definitions match

4. Business Logic Validation
   ├─ Dynamic field values valid
   ├─ Targeting config valid
   └─ Budget config valid

5. Launch Validation
   └─ All requirements met
```

## Data Flow

```
┌────────────────────────────────────────────────────────┐
│                     Data Pipeline                       │
└────────────────────────────────────────────────────────┘

1. Template Fetch
   ┌──────────────────────────────────────┐
   │ GET /api/templates                   │
   │ ↓                                    │
   │ React Query Cache (30s)              │
   │ ↓                                    │
   │ TemplateSelector Display             │
   └──────────────────────────────────────┘

2. Template Selection
   ┌──────────────────────────────────────┐
   │ User clicks "Use Template"           │
   │ ↓                                    │
   │ setSelectedTemplate(template)        │
   │ ↓                                    │
   │ parseFieldDefinitions()              │
   │ ↓                                    │
   │ DynamicFieldsForm Render             │
   └──────────────────────────────────────┘

3. Field Value Collection
   ┌──────────────────────────────────────┐
   │ User fills form                      │
   │ ↓                                    │
   │ React Hook Form validates            │
   │ ↓                                    │
   │ onChange(values, isValid)            │
   │ ↓                                    │
   │ setFieldValues(values)               │
   └──────────────────────────────────────┘

4. Configuration Collection
   ┌──────────────────────────────────────┐
   │ User configures targeting & budget   │
   │ ↓                                    │
   │ Form validates                       │
   │ ↓                                    │
   │ onChange(targeting, budget, isValid) │
   │ ↓                                    │
   │ setTargeting(), setBudget()          │
   └──────────────────────────────────────┘

5. Preview Generation
   ┌──────────────────────────────────────┐
   │ resolveDynamicFields(template, values)│
   │ ↓                                    │
   │ Render resolved ad copy              │
   │ ↓                                    │
   │ Highlight dynamic field values       │
   └──────────────────────────────────────┘

6. Campaign Launch
   ┌──────────────────────────────────────┐
   │ POST /api/campaigns/launch           │
   │ ├─ Validate session                  │
   │ ├─ Validate schema                   │
   │ ├─ Check template exists             │
   │ ├─ Check ad account access           │
   │ ├─ Validate field values             │
   │ ├─ Validate launch config            │
   │ └─ Create campaign (stub)            │
   │ ↓                                    │
   │ Return campaign object               │
   │ ↓                                    │
   │ Redirect to campaigns list           │
   └──────────────────────────────────────┘
```

## Error Handling

```
┌────────────────────────────────────────────────────────┐
│                    Error Scenarios                      │
└────────────────────────────────────────────────────────┘

API Errors
──────────
401 Unauthorized
  → Show: "Please log in to continue"
  → Action: Redirect to login

403 Forbidden
  → Show: "You don't have access to this ad account"
  → Action: Allow back navigation

404 Not Found
  → Show: "Template not found"
  → Action: Return to template selection

400 Bad Request
  → Show: Specific field errors
  → Action: Highlight invalid fields

500 Server Error
  → Show: "Something went wrong. Please try again"
  → Action: Allow retry

Validation Errors
─────────────────
Field Validation
  → Show: Error message below field
  → Action: Disable "Next" button

Form Validation
  → Show: Summary of errors
  → Action: Scroll to first error

Launch Validation
  → Show: Error in LaunchNavigation
  → Action: Stay on current step

Network Errors
──────────────
Request Failed
  → Show: "Network error. Check connection"
  → Action: Allow retry

Timeout
  → Show: "Request timeout. Please try again"
  → Action: Allow retry
```
